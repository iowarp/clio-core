**Standing caveat:** every parity test asserts NUMERICAL agreement, never EXECUTION
LOCALITY. All of them would still pass if the port computed upstream's exact values in a
host loop — which Phase 20 showed the default functional test actually does. That is why the
`nsys` profiling in phases 20-22 was necessary and why a green suite alone is not evidence
for rows 79-81.
