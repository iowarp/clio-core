1. Install WinFsp

Download and run the installer from winfsp.dev. The default components are enough to mount. To build the adapter from source, also install the developer files: choose them in the installer, or run msiexec /i winfsp.msi ADDLOCAL=ALL.

2. Install CLIO Core

PS> py -3.12 -m pip install iowarp-core
PS> clio_run --help

The clio_cte_fuse command adds WinFsp's bin folder to PATH itself, so you do not need to edit the system PATH.

3. Start the runtime and mount

Use two PowerShell windows. In the first:

PS> clio_run start

In the second:

Drive letter

PS> $env:CLIO_WITH_RUNTIME = "0"
PS> clio_cte_fuse Z: -f

Folder

PS> $env:CLIO_WITH_RUNTIME = "0"
PS> clio_cte_fuse C:\iowarp\cte -f

The folder's parent must exist. WinFsp creates the mount folder itself.

4. Use it

PS> Copy-Item -Recurse $HOME\Documents\results Z:\
PS> Get-ChildItem Z:\results

The drive appears in File Explorer. Python, Excel, ParaView and other applications can open files there directly.

5. Unmount

Stop the daemon, then the runtime:

PS> Stop-Process -Name clio_cte_fuse -Force
PS> clio_run stop

Building from source

PS> cmake --preset windows-release -DCLIO_CTE_ENABLE_FUSE_ADAPTER=ON
PS> cmake --build build --config Release

Set VCPKG_ROOT first. WinFsp is found under %ProgramFiles(x86)%\WinFsp, or pass -DWINFSP_ROOT=.

If something goes wrong

  • A missing winfsp-x64.dll: WinFsp is not installed, or was installed without its core component.
  • The drive letter is in use: pick another letter, or check Get-PSDrive.
  • Files are invisible to Python: CLIO_WITH_RUNTIME was not 0 in the mount window.
