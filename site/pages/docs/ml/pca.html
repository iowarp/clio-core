What it does

The pass is deterministic in block order, so the covariance and the components are reproducible across cache sizes. Components are sorted by decreasing variance and sign-normalised so that each component's largest-magnitude entry is positive. All nf components are returned; select the leading ones yourself.

Rows

Every column is a feature. clio_ml.COLUMNS["pca"] is 0.

Python

import numpy as np, clio_ml as cm
X = np.random.default_rng(0).normal(size=(4096, 8)).astype(np.float32)

r = cm.fit_pca(X)
components = np.asarray(r.components).reshape(r.nf, r.nf)   # row k = k-th component
top3 = components[:3]
print(r.explained_variance[:3])
projected = (X - np.asarray(r.mean)) @ top3.T
  • fit_pca(X, **options).
  • Options (PcaOptions): threads (256).
  • Result PcaResult: nf, mean (nf), components (nf*nf, row k is the k-th component), explained_variance (nf, descending), stats.
  • No one-row predictor; project rows with NumPy as above.

struct PcaOptions {
  u32 threads = 256;
  ClusterExchange cluster;  // global_rows used as n when active
};

  u32 nf = 0;
  std::vector mean;                // nf
  std::vector components;          // nf*nf
  std::vector explained_variance;  // nf, descending
  VecStats stats;
  std::vector Flatten() const;
};
