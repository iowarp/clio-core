What it does

Expected topic-word counts are summed in fixed row order, so the topics are bit-reproducible. The model holds the topic-word distributions only; per-document topic mixtures are not returned.

Rows

One document per row with vocab_size columns of word counts. clio_ml.COLUMNS["lda"] is 0.

Python

import numpy as np, clio_ml as cm
docs = np.random.default_rng(1).poisson(2.0, (4096, 8)).astype(np.float32)

r = cm.fit_lda(docs, k=2, iters=3)
topics = np.asarray(r.model.topics).reshape(r.model.K, r.model.V)   # each row sums to 1
print(topics.argsort(axis=1)[:, ::-1][:, :3])                        # top-3 words per topic
  • fit_lda(X, **options).
  • Options (LdaOptions): k (3), iters (30), inner (20, per-document E-step iterations), alpha (0.1, document-topic Dirichlet), eta (0.01, topic-word smoothing), seed (1), threads (256).
  • Result LdaResult: model (LdaModel with V, K and topics, K*V) and stats.
  • No predictor.

C++

struct LdaOptions {
  u32 k = 3;            // <= 16
  u32 iters = 30;
  u32 inner = 20;
  float alpha = 0.1f;
  float eta = 0.01f;
  u32 seed = 1;
  u32 threads = 256;
  ClusterExchange cluster;
};
struct LdaModel {
  u32 V = 0, K = 0;
  std::vector topics;  // K*V
  std::vector Flatten() const;
};
struct LdaResult { LdaModel model; VecStats stats; };
LdaResult FitLda(Dataset &ds, const LdaOptions &opt);
LdaResult FitLdaPlain(const float *data, u64 n_docs, u32 vocab, u64 elems_per_page,
                      u32 nblocks, const LdaOptions &opt);
