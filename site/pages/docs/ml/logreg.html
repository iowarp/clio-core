What it does

Each iteration is one paged pass that sums the log-loss gradient over all rows, followed by one fixed-step update. No regularisation, no early stop. The recorded loss is the mean log-loss before each update. For more than two classes use multinomial logistic regression, which uses L-BFGS.

Rows

n_features feature columns followed by a 0/1 label. clio_ml.COLUMNS["logreg"] is 1.

Python

import numpy as np, clio_ml as cm
rng = np.random.default_rng(1)
X = rng.normal(size=(4096, 7)).astype(np.float32)
y = (X[:, 0] + X[:, 1] > 0).astype(np.float32)
data = np.column_stack([X, y]).astype(np.float32)

r = cm.fit_logreg(data, iters=20, learning_rate=0.1)
p = cm.predict("logreg", r, data[0, :7])       # P(y = 1) for one row
print(r.weights, p)
  • fit_logreg(X, **options) calls the GLM engine with GlmKind.logistic.
  • Options (GlmOptions): iters (100), learning_rate (0.1), threads (256).
  • Result GlmResult: weights (coefficients, then intercept), loss_history, stats.
  • predict("logreg", r, x) returns the probability of class 1.
