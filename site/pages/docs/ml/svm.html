What it does

The GLM engine with GlmKind::kSvm: one paged pass per iteration sums the hinge-loss subgradient, then one fixed-step update. No regularisation and no early stop. The recorded loss is the mean hinge loss before each update.

Rows

n_features feature columns followed by a 0/1 label. clio_ml.COLUMNS["svm"] is 1.

Python

import numpy as np, clio_ml as cm
rng = np.random.default_rng(1)
X = rng.normal(size=(4096, 7)).astype(np.float32)
y = (X[:, 0] + X[:, 1] > 0).astype(np.float32)
data = np.column_stack([X, y]).astype(np.float32)

r = cm.fit_svm(data, iters=20, learning_rate=0.1)
margin = cm.predict("svm", r, data[0, :7])     # signed linear value
print(r.weights, margin)
  • fit_svm(X, **options) calls the GLM engine with GlmKind.svm.
  • Options (GlmOptions): iters (100), learning_rate (0.1), threads (256).
  • Result GlmResult: weights (coefficients, then intercept), loss_history, stats.
  • predict("svm", r, x) returns GlmPredict(GlmKind.svm, ...), the linear value w . x + b; its sign is the class.
