What it does

Counts are integers, so the result is exact and independent of paging or block order. Itemsets are returned sorted by size and then by items. Rules have a single consequent item.

Rows

One transaction per row with one 0/1 column per item. clio_ml.COLUMNS["fim"] is 0.

Python

import numpy as np, clio_ml as cm
T = (np.random.default_rng(1).random((4096, 8)) < 0.4).astype(np.float32)

r = cm.fit_fim(T, min_support=0.1, min_confidence=0.6, max_size=4)
for s in r.itemsets[:5]:
    print(s.items, s.count)
for rule in r.rules[:5]:
    print(rule.antecedent, "->", rule.consequent, rule.confidence, rule.lift)
  • fit_fim(X, **options) calls MineFrequentItemsets.
  • Options (FrequentItemsetOptions): min_support (0.05, fraction of transactions), min_confidence (0.6, for rules), max_size (4), threads (256).
  • Result FrequentItemsetResult: itemsets (list of Itemset with ascending items and count), rules (list of AssociationRule with antecedent, consequent, confidence, lift), stats.

C++

struct FrequentItemsetOptions {
  float min_support = 0.05f;
  float min_confidence = 0.6f;
  u32 max_size = 4;
  u32 threads = 256;
  ClusterExchange cluster;
};
struct Itemset { std::vector items; u64 count = 0; };
struct AssociationRule {
  std::vector antecedent;
  u32 consequent = 0;
  double confidence = 0, lift = 0;
};
struct FrequentItemsetResult {
  std::vector itemsets;       // sorted by (size, items)
  std::vector rules;
  VecStats stats;
  std::vector Flatten() const;
};
FrequentItemsetResult MineFrequentItemsets(Dataset &ds, const FrequentItemsetOptions &opt);
FrequentItemsetResult MineFrequentItemsetsPlain(const float *data, u64 n_rows, u32 n_items,
                                                u64 elems_per_page, u32 nblocks,
                                                const FrequentItemsetOptions &opt);
FrequentItemsetResult MineFrequentItemsetsReference(/* same arguments */);
