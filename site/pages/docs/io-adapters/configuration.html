Pools the runtime must compose

AdapterNeedsHow it finds it
POSIX, STDIO, MPI-IOA clio_cte_filesystem pool, over a CTE chainBy pool name clio_cte_filesystem, or CLIO_CFS_POOL (a name, or an id such as 560.0). The interceptors create no pool.
HDF5 VOL, ADIOS2A clio_cte_core pool with at least one storage tierBy pool name clio_cte_core, or CLIO_CTE_POOL=major.minor.
HDF5 VFDNothing, unless the read tier is on; then both of the aboveAs above.

The default configuration (context-runtime/config/clio_default.yaml, copied to ~/.clio/clio.yaml) composes the filesystem pool at 560.0, so the interceptors work with a plain clio-run start. Its CTE core pool is named cte_main, which the HDF5 connectors' lookup by name misses; rename it to clio_cte_core, or start from context-transfer-engine/adapter/config/clio_hdf5_quickstart.yaml, a small RAM-only configuration whose pool already has that name. The minimum for the HDF5 connectors and the ADIOS2 engine is the compose section of that file:

compose:
  - mod_name: clio_bdev
    pool_name: "ram::chi_default_bdev"
    pool_query: local
    pool_id: "301.0"
    bdev_type: ram
    capacity: "256MB"
  - mod_name: clio_cte_core
    pool_name: clio_cte_core          # the name clients look up
    pool_query: local
    pool_id: "512.0"
    storage:
      - path: "ram::cte_ram_tier1"
        bdev_type: "ram"
        capacity_limit: "256MB"
        score: 1.0
    dpe:
      dpe_type: "max_bw"

The filesystem pool's own keys are in the Context FS reference; the compose file format is in the runtime reference.

Variables every adapter reads

VariableDefaultEffect
CLIO_SERVER_CONF~/.clio/clio.yamlRuntime configuration. Clients read it too: set it to the file the runtime was started with. A missing or unparseable file aborts the client process.
CLIO_WITH_RUNTIMEunset (attach only)1 makes the process try to become the runtime itself and attach if one already owns the port, as the adapters' tests do. 0 or unset attaches to a running clio-run.
CLIO_WAIT_SERVER30Seconds a client waits for a runtime at attach. 0 fails immediately, -1 waits forever.
CLIO_XTCPClient transport to the runtime: SHM, TCP or IPC. See the runtime docs.
CLIO_REQUIRE_RUNTIMEoffHDF5 connectors only. Any value other than empty, 0, off, false or no makes an open fail when the CLIO tier cannot be reached, instead of falling back to native-only. It does not override a cache that was switched off on purpose.

POSIX, STDIO and MPI-IO interceptors

VariableDefaultEffect
LD_PRELOADnoneLoads the interceptor: libclio_cte_posix.so, libclio_cte_stdio.so, libclio_cte_mpiio.so (space- or colon-separated for several). The MPI-IO library must load before libmpi.
CLIO_CFS_POOLclio_cte_filesystemThe filesystem pool to bind: a pool name, or major.minor for an id.
CLIO_CFS_SHM_READon0 turns off serving committed pages straight from shared memory; every read then goes to the filesystem module. For diagnosis.

Paths are selected by the clio:: marker, not by configuration: a path is intercepted when it starts with clio:: or has a component starting with it, and the marker is removed to form the clio-fs path. Descriptors start at 8192. There is no other per-file setting.

HDF5 VOL connector

Selection

VariableValue
HDF5_PLUGIN_PATHDirectory containing libclio_hdf5_vol.so
HDF5_VOL_CONNECTORclio, optionally followed by a space and a config string: clio cache=0;chunk_size=1048576

Config string keys: cache (boolean: 1/on/true/yes or 0/off/false/no), chunk_size (plain decimal bytes, no unit suffix, greater than 0), under_vol and under_info (accepted, not applied: the connector always delegates to the native connector). Any other key fails the open.

Environment

VariableDefaultEffect
CLIO_VOL_CACHEon0/off/false/no: pure pass-through, no runtime needed.
CLIO_VOL_CHUNK_SIZE65536Blob size of cached dataset images, in bytes. Overrides chunk_size from the string or info struct. Part of the coherence stamp.
CLIO_VOL_ADMITread-missWhen to stage: write, read-miss, second-access. Default is write when CLIO_STAMP_SETTLE_MAX_NS is set.
CLIO_VOL_ADMIT_COSTon0 disables the cost gate and stages every eligible transfer.
CLIO_VOL_TIER_FIXED_US60Cost-model seed: fixed microseconds per tier request.
CLIO_VOL_TIER_MBPS1200Cost-model seed: tier bandwidth in MB/s.
CLIO_VOL_MIN_STAGE_BYTES0Do not stage images smaller than this.
CLIO_VOL_MAX_SERVE_BYTES1073741824Larger datasets are not served from the cache for partial reads.
CLIO_VOL_TIER_RETRY_MS5000Back-off after the tier reports it is full, before staging is tried again.
