OMNI file schema

An OMNI file is YAML. The loader reads one top-level key, transfers, which must be a sequence. Any other top-level key is ignored. Each transfer is a map; src, dst and format are required, and a transfer that omits one fails the load with a message naming it by 1-based position. A per-transfer key not in the list below is logged as a warning and ignored.

KeyTypeDefaultMeaning
srcstringrequiredSource URL. The scheme selects the assimilator: file::, string::, hdf5::, http://, https://, s3://, gs://, gcs://, globus://.
dststringrequiredDestination, iowarp::<tag name>.
formatstringrequiredbinary, hdf5, hdf5_vol or globus. The HDF5 assimilator acts on hdf5_vol; the run-step logic treats any format starting with hdf5 as HDF5.
depends_onstring""The exact src or dst of an earlier transfer. Checked before anything is scheduled; a dependency on a later transfer, on itself, or on nothing fails the file with result code -3.
range_offinteger0Byte offset into the source.
range_sizeinteger0Bytes to read from range_off. 0 means to the end.
src_tokenstring""Source credential. Environment-expanded. Sent as Authorization: Bearer for HTTP sources and used as the Globus access token.
dst_tokenstring""Destination credential. Environment-expanded. Carried in the context; no shipped assimilator reads it.
dataset_filtermapnoneHolds include_patterns and exclude_patterns, each a sequence of glob patterns (*, ?, []; * crosses /). Used by the HDF5 assimilator. Empty include means include all.
runpathnoneScript run by clio_cae before submission, as script <source> <run_out>. Environment-expanded; relative to the OMNI file's directory. Requires run_out.
run_outpathnoneThe file the script writes; it replaces the source. Same expansion rules. Requires run.

Fields of AssimilationCtx that have no OMNI key (src_data, s3_region, s3_profile, on_fault, chunk_size, blob_prefix) can only be set from code.

clio_cae tool

$ clio_cae <omni_file_path>

One positional argument, the OMNI file. Any other argument count prints the usage and exits 1. clio_cae_omni is an installed alias. The tool:

  1. Initializes a runtime client (CLIO_INIT(kClient, false)) and exits 1 if the runtime is unreachable.
  2. Loads the file with LoadOmni, collecting run steps.
  3. Executes the run steps in order with ExecuteRunSteps. On failure it exits 1 having submitted nothing.
  4. Submits one ParseOmni task to pool 400.0 and waits.
  5. Exits 1 if result_code_ or the task framework code is non-zero, printing error_message_, or if the request was non-empty and num_tasks_scheduled_ is 0. Otherwise prints the count and exits 0.

Environment: the tool honors the runtime client variables (CLIO_SERVER_CONF, CLIO_WITH_RUNTIME, and on Windows CLIO_SERVER_ADDR=127.0.0.1 with CLIO_BIND_ADDR=127.0.0.1). It reads no CAE-specific variables itself.

ParseOmni result codes

The ParseOmniTask outputs are num_tasks_scheduled_ (u32), result_code_ (u32, printed signed) and error_message_. Transfers are processed in order and the task stops at the first failure, so num_tasks_scheduled_ is the count completed before it.

  • 0: every transfer ran.
  • -1: the serialized context list could not be deserialized.
  • -2: no assimilator for a source scheme, including a scheme whose support was not compiled in.
  • -3: a depends_on that cannot be honored.
  • -9: HDF5 include patterns matched no dataset.
  • -20: an on_fault transfer whose assimilator cannot ingest per blob.
  • Other non-zero: the assimilator's own error code, with error_message_ set to Assimilator failed, or a CTE return code during on_fault setup with on_fault assimilation setup failed.

AssimilationCtx

Declared in clio_cae/core/factory/assimilation_ctx.h, namespace clio::cae::core. It is serialized into the ParseOmni task.

struct AssimilationCtx {
  std::string src;          // source URL
  std::string dst;          // iowarp::<tag>
  std::string format;       // binary, hdf5, hdf5_vol, globus
  std::string depends_on;   // "" if none
  size_t range_off;         // 0
  size_t range_size;        // 0 = whole source
  std::string src_token;
  std::string dst_token;
  std::string s3_region;    // -> AWS_DEFAULT_REGION for the S3 helper; "" = inherit
  std::string s3_profile;   // -> AWS_PROFILE for the S3 helper; "" = inherit
  std::string src_data;     // payload for string:: sources
  bool on_fault = false;    // register as fault handler instead of ingesting now
  size_t chunk_size = 0;    // bytes per blob; 0 = assimilator default (1 MiB for files)
  std::string blob_prefix = "chunk_";   // "" names blobs "0", "1", ...
  std::vector<std::string> include_patterns;
  std::vector<std::string> exclude_patterns;

  AssimilationCtx();
  AssimilationCtx(const std::string& src_url, const std::string& dst_url,
                  const std::string& data_format, const std::string& dependency = "",
                  size_t offset = 0, size_t size = 0,
                  const std::string& source_token = "", const std::string& dest_token = "");
};

// Returns "" when every depends_on names an earlier context, else a message.
std::string CheckDependencies(const std::vector<AssimilationCtx>& ctxs);

Environment variables

Read by the runtime process unless noted. Values in parentheses are defaults.

Ingest on fault

  • CLIO_CAE_FAULT_RESERVE_MB (512): megabytes kept free across the node's targets. A fault-ingested blob that would cross that line is served from the source without being stored.
  • CLIO_CAE_FAULT_STORE (1): set to 0 to never store fault-ingested blobs, giving pure read-through.
  • CLIO_CAE_FAULT_STATS (unset): set to 1 to log the fault stage counters every 5 seconds.
  • CLIO_CAE_REF_IO_THREADS (32): size of the thread pool that performs blocking source I/O for faults. 0 is treated as 1.

HTTP sources

  • CAE_HTTP_AUTH_FILE (~/.clio/cae_http_auth.ini): INI file of per-host or per-prefix sections with query.*, header.*, bearer_token, user, password and client (curl or wget). ${VAR} in a value is expanded; an unset variable is an error. A file holding a secret must be mode 600.
  • CAE_HTTP_STREAMS (8, 1 to 64): parallel ranged GETs.
  • CAE_HTTP_PART_MB (64, 1 to 4096): bytes per ranged GET, in MiB.
  • CAE_HTTP_PART_RETRIES (5, 0 to 100) and CAE_HTTP_BACKOFF_MS (1000, 0 to 60000): per-part retry policy.
  • CAE_HTTP_OVERWRITE (0): set to 1 to overwrite an existing download.
  • CAE_HTTP_PROGRESS_S (30, 0 to 3600): seconds between progress log lines.
  • CAE_HTTP_CURL, CAE_HTTP_WGET: paths of the client programs.
  • CAE_HTTP_TOKEN: read by the standalone cae_http_tool only, in place of src_token.

S3 sources

  • Standard AWS variables: AWS_ACCESS_KEY_ID, AWS_SECRET_ACCESS_KEY, AWS_SESSION_TOKEN, AWS_PROFILE, AWS_DEFAULT_REGION (us-east-1 in the helper), S3_ENDPOINT or AWS_ENDPOINT_URL for S3-compatible stores (path-style addressing), AWS_NO_SIGN_REQUEST=1 to force anonymous requests.
  • CAE_S3_STREAMS (up to 64): parallel GET streams.
  • CAE_S3_PART_MB (up to 1024): part size in MiB.
  • CAE_S3_MAX_RESUMES (1 to 1000), CAE_S3_BACKOFF_MS (0 to 30000), CAE_S3_PART_RETRIES (0 to 100): resume policy for a GET stream that ends short.
  • CAE_S3_TOOL: read by the S3 read benchmark to locate cae_s3_tool.

Other sources

  • GLOBUS_ACCESS_TOKEN: Globus token when src_token is empty. GLOBUS_HTTPS_ACCESS_TOKEN is read for the HTTPS collection path.
  • GCS_ENDPOINT: overrides the Google Cloud Storage endpoint.

Client side

  • CLIO_CTE_POOL (major.minor): binds the process's CTE client, which CLIO_CAE_CLIENT_INIT creates, to an interposing pool. Needed for semantic queries; see the CEE usage page.
  • CLIO_WITH_RUNTIME: 1 or true makes a client try to start a runtime in-process before attaching. clio_cae and the CEE default to attaching only.
