Six regimes, three phases, chunk by chunk

Six synthetic regimes spanning entropy 0.03–7.47 bits/byte, deliberately decorrelated so the network cannot ride entropy alone. 100 chunks of 4 MiB each, 600 in a continuous stream — 2.3 GiB per phase — written through the real compressor. Each phase runs in its own process, so the weights come fresh off the .nnwt and nothing carries between them.

cost model balanced
balanced — cost = 1·ct + 1·dt + 1·size/(ratio·bw), bw = 5 GB/s. Upstream's defaults (g_rank_w0/w1/w2, g_measured_bw_bytes_per_ms); no CLIO_NEUROPRESS_COST_W_* override was set.
The two alternatives are ratio (W_CT=0 W_DT=0 → cost is the I/O term alone) and speed (W_IO=0 → cost is the two times alone).
Balanced is balanced in name only at this chunk size: the I/O term is 0.839/ratio ms while both time terms are floored at 1 ms, so the ratio contributes ~0.4–3% of the cost and the shipped model is effectively a latency model. That is why a chunk can carry a 4× ratio error and still sit below the SGD gate.

Every chunk, in order

The dataset as one continuous stream — 600 chunks, regime in its own column. For each phase: the model's prediction, the measured value and the error, for all three metrics plus the cost. cost mape is the only one that gates SGD. decomp reads zero because decompression is never measured at write time — upstream substitutes the prediction, so the term cancels.

Labels are real nvcomp output measured on an A100. cost = w0·ct + w1·dt + w2·size/(ratio·bw) with w0=w1=w2=1 and bw=5 GB/s — the same weights and clamps upstream NeuroPress ranks on, and the only quantity that gates SGD. The three per-metric MAPEs are diagnostics: each is normalised by the actual value, so under-prediction saturates at 1.0 while over-prediction is unbounded. decomp-time MAPE is structurally zero — decompression is never measured at write time, so upstream substitutes the prediction and the term cancels on both sides of the cost.
